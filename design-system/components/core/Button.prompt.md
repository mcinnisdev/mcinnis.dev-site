The brand's action control — 4px radius, Space Grotesk medium, orange reserved for the single primary action on a view.

```jsx
<Button variant="primary" icon="arrow-right" href="/projects/">Projects</Button>
<Button variant="secondary" size="sm">Blog</Button>
```

Variants: `primary` (orange, deepens on hover with a warm glow), `secondary` (paper + hairline border), `ghost` (orange text, soft tint on hover), `inverse` (paper fill for ink sections). Sizes sm 32 / md 40 / lg 48. Press = 0.985 scale. Set `href` for links.
