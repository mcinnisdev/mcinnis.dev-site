Default container for asides, meta panels and callout blocks. (Projects use `ProjectCard`, not this.)

```jsx
<Card variant="sunken" padding="var(--space-4)">…</Card>
```

Variants: `raised` (default, `--ink-800`), `sunken` (`--ink-950`, for inset panels), `accent` (orange wash — sparingly), `outline`, `paper` (light slab; only for print sheets or an embed on a white host).
