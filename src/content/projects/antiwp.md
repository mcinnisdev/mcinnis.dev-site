Your website does not need to be a software project. Most small business sites are five pages that never change, and they are being run on a platform built to publish a newspaper — billed accordingly, forever.

## What it argues

Not that WordPress is bad. That it is the wrong shape for a brochure site, and that nobody quotes you the real number when you sign up.

So the posts do the arithmetic instead. Hosting, licences, the annual refresh, the emergency call: about $1,340 over five years for a site that could have cost nothing. Nineteen plugins running on five pages. Forty-three ways into a site that needs zero. Fourteen kilobytes is roughly what a site like that should weigh.

The replacement is not a framework. Need a form? There is a service for that. Need analytics? Same. What is left is HTML on a free tier, with no updates to apply and no admin login to defend.

## The format

Teardowns, one at a time — what the five-year bill actually looks like, where to put a static site for $0 compared honestly, how to run a contact form with no database, no plugin and no backend. The site practises what it argues: no cookies, no build step, no admin login.

## Where it sends people

Some sites genuinely need a CMS — a real publishing schedule, several editors, a catalogue that changes. AntiWP says so plainly and points those readers at Web Dens, because arguing against the tool I also build in would be dishonest if I only ever argued one way.
